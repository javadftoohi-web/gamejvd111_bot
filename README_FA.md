# Game Hub فارسی — نسخه توسعه‌یافته اولیه

ربات هدف: `@gamejvd111_bot`

## چه چیزهایی در این بسته وجود دارد؟
- منوی دسته‌بندی‌شده برای ۳۶ بازی/حالت رقابتی
- ربات تلگرام با فرمان‌های `/start`, `/games`, `/top`, `/profile`
- پیاده‌سازی اولیه بازی اطلاعات عمومی، سنگ‌کاغذقیچی و حدس عدد
- نمونه اولیه چالش اطلاعات عمومی در گروه
- صفحه وب ساده برای Mini App که فهرست ۳۶ بازی و وضعیت توسعه را نمایش می‌دهد
- پایگاه داده SQLite برای پروفایل و امتیازها

## مهم: وضعیت واقعی پیاده‌سازی
این بسته **نسخه تولید نهایی نیست**. فقط بازی‌هایی که در کد `games.py` با وضعیت `implemented` علامت خورده‌اند و جریان‌های مربوطه در `bot.py` پیاده‌سازی شده‌اند، تا حد نمونه اولیه آماده‌اند. چالش گروهی فعلی محدودیت‌ها و نواقص دارد و برای رقابت زنده حرفه‌ای باید بهبود یابد. Mini App فعلی فهرست بازی‌ها را نشان می‌دهد و هنوز احراز هویت امن Telegram `initData`، اجرای بازی از API یا همگام‌سازی امتیاز را انجام نمی‌دهد.

## اجرای ربات
1. Python 3.11+.
2. نصب وابستگی‌ها: `pip install -r requirements.txt`
3. تنظیم `TELEGRAM_BOT_TOKEN` در Secrets/Environment Variables میزبان.
4. اجرای `python bot.py`

## اجرای Mini App
- پوشه `webapp` باید روی یک میزبان HTTPS منتشر شود.
- مقدار `MINI_APP_URL` را در secrets به URL واقعی صفحه تنظیم کنید.
- بدون HTTPS و تنظیم URL واقعی، دکمه Mini App در منوی ربات ظاهر نمی‌شود.

## نکته پایگاه داده
SQLite برای نمونه اولیه مناسب است. در میزبانی چندنمونه‌ای یا استفاده پرترافیک، PostgreSQL و دیسک/پایگاه داده پایدار پیشنهاد می‌شود. مطمئن شوید محیط میزبانی فایل SQLite را پس از restart حذف نمی‌کند.

## کارهای لازم پیش از انتشار عمومی
- افزودن اعتبارسنجی سمت سرور Telegram Mini App `initData`
- API امن برای بازی‌ها و پروفایل‌ها
- قفل و زمان‌بندی درست برای دورهای گروهی، انقضای سؤال و جلوگیری از رأی تکراری
- ذخیره وضعیت بازی‌های فعال در دیتابیس/Redis، نه حافظه موقت
- آزمون‌های خودکار، محدودسازی نرخ درخواست و کنترل امتیازدهی
- پیاده‌سازی واقعی بازی‌های برنامه‌ریزی‌شده
- تنظیم حریم خصوصی و متن راهنمای ربات
